# VoidTV — Plataforma de Streaming de Filmes Web
## Descrição da Aplicação
- O VoidTV é uma aplicação Web de streaming desenvolvida para centralizar e facilitar o acesso a obras audiovisuais e filmes de nicho.

- O sistema permite navegação por catálogos, reprodução de vídeos diretamente na plataforma, gerenciamento de listas de favoritos e publicação de resenhas pela comunidade.

## Problema Resolvido
- A dispersão e a falta de visibilidade de conteúdos audiovisuais independentes e de nicho em plataformas de streaming convencionais.

## Tecnologias Utilizadas
- **Front-end:** HTML5, CSS3, Bootstrap, JavaScript (Node/Express para renderização ou SPA).
- **Back-end:** Node.js, Express.
- **Banco de Dados:** SQLite / PostgreSQL.
- **Controle de Versão:** Git / GitHub.
